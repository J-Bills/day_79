# Section 79: Day 79 - Advanced - Analysing the Nobel Prize with Plotly, Matplotlib & Seaborn

This project will bring together many of the tools and techniques that we've covered previously. While we will review many concepts from the past, you'll also learn a lot of new things.

## Learning Objectives

Today, you will learn to:

- Create a **Choropleth** to display data on a map.
- Create **Bar Charts** showing different segments of the data using Plotly.
- Create **Sunburst Charts** with Plotly.
- Use Seaborn's `.lmplot()` and show best-fit lines across multiple categories using the `row`, `hue`, and `lowess` parameters.
- Understand how a different picture emerges when looking at the same data in different ways (e.g., box plots vs. a time series analysis).
- See the distribution of our data and visualize descriptive statistics with the help of a **Histogram** in Seaborn.
